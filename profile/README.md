<h1 align="center">ConectAgro</h1>
<h3 align="center">Incentivando uma alimentação mais saudável na sua região</h3>

<p align="center">
Esta organização foi criada com o objetivo de gerenciar o desenvolvimento de uma plataforma WEB que incentiva o consumo de agricultura familiar, aproximando pequenos produtores locais dos moradores dos bairros em que eles já produzem.
</p>

<p align="center">
O projeto é desenvolvido na disciplina MAC0332 - Engenharia de Software e reúne, em um repositório central, a aplicação WEB, o backend compartilhado e a infraestrutura necessária para executá-los em um monorepo.
</p>

## Stack

- **Backend**: FastAPI + SQLModel + PostgreSQL
- **Frontend**: React + Vite + TypeScript + Tailwind CSS
- **Autenticação**: OAuth 2.0 (Google) sem cadastro por e-mail/senha
- **Infra**: Docker Compose: o backend serve o build de produção do frontend
